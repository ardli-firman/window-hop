# Window Hop

Window Hop digunakan pada komputer perawat poliklinik yang terhubung ke monitor antrian.

## Language

**Profil**:
Konfigurasi satu aplikasi beserta parameter peluncuran kustom dan satu monitor tujuannya.

**Monitor tujuan**:
Monitor yang dipilih sebagai tempat menampilkan jendela aplikasi dalam profil.
_Avoid_: Window 2, layar kedua

**Monitor antrian**:
Monitor yang menampilkan aplikasi untuk kebutuhan antrian poliklinik.

**Shortcut profil**:
Pintasan untuk mengaktifkan profil Window Hop.

**Profil startup**:
Profil pilihan yang diaktifkan otomatis setelah pengguna login Windows.

**Window profil**:
Jendela aplikasi yang dijalankan oleh suatu profil dan digunakan kembali saat profil tersebut diaktifkan ulang.

**Sesi browser profil**:
Data dan sesi browser yang khusus digunakan oleh satu profil Window Hop, terpisah dari browser kerja perawat dan profil Window Hop lainnya.
